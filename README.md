
# Signature-Transform
This repository contains python code for a basic implementation of the signature transform as defined below:

<img width="716" height="359" alt="Screenshot 2026-08-10 183335" src="https://github.com/user-attachments/assets/ce4e41b2-4ffa-46bc-a5ff-ee834aedf6dc" />

Use main_compute_signature to compute the signature transform. main_compute_signature takes two inputs, stream and depth. Stream is a 2-D numpy array of floats. Each row of the 2-D array should be of length at least two. Depth is an integer greater than two. 

main_compute_signature should give the same results as the esig package available at https://pypi.org/project/esig/ .
